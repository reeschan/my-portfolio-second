## 活かせる経験・知識・技術

### 要件定義・仕様調整
- ステークホルダーからの要望をヒアリングし、機能要件を策定。
- アジャイル開発において、10人規模のチームリソースや工数を考慮し、最適な提案を実施。
- 連携システムがある場合、技術的制約や相手方のリソースを踏まえた実現可能なプランを複数提示。

### フルスタック開発・アーキテクチャ設計
- 設計から実装、テスト、リリースまでフルスタックで担当可能。
- テックリード・アーキテクトとしてプロジェクトに参画し、技術選定・システム設計をリード。
- フロントエンド・バックエンド・クラウドインフラを統合したアプリケーション開発の経験。

### チームリーダー経験
- 15人規模のチームリーダーとして、各メンバーの案件・タスクを管理。
- 業務負荷を考慮し、上位マネージャーと連携しながら適切にタスクを割り振り。
- 各プロダクトの技術スタックを把握し、トラブル発生時には迅速に調査・解決を支援。

### クラウドプラットフォーム・IaC
- AWSを活用したWebアプリケーションの設計・開発。
- Terraform・AWS CDKを用いたInfrastructure as Code（IaC）の構築。
- セキュリティ・コストを考慮したクラウド環境の最適化（AWS認定資格9種取得）。
- AzureやGCPの基礎知識。

### テスト設計・品質管理
- 大規模機能実装時にテストマトリクスを作成し、QAレベルのテスト仕様書を策定。
- バグ発生を最小限に抑えるためのテスト戦略を実施。
- 自動テスト（ユニットテスト・E2Eテスト）を取り入れた開発フローを構築。

### サーバ・ストレージ・データベースの知識
- Windows / Linuxサーバの構築・運用経験。
- NetApp・Isilonなどのファイルストレージサーバの運用。
- SQL Server・Oracle DBの管理、監査システムの知見。

### アジャイル・スクラム開発
- スクラムの各ロール・マインドセット・進め方を理解し、開発プロセスを最適化。
- プロダクトオーナーとの連携を強化し、プロダクト価値向上のための提案・改善を主導。
- チーム内でのアジャイル文化の定着・促進を実施。

### デジタルマーケティング
- Google Analyticsを活用したカスタムレポート設定、Looker Studio（BIツール）との連携。
- CV・ユーザーデータを可視化するダッシュボードの作成。
- 収集データをもとにプロダクトの課題を分析し、工数を考慮した改善策を提案。

### SRE（Site Reliability Engineering）
- New Relicを用いたアプリケーション監視（アクセス履歴・APIエラーモニタリング）。
- 障害発生時のアラート設定、インシデント対応。
- サービスの安定稼働を目的としたパフォーマンス最適化・システム改善。

- リリース作業

**実績・取り組み**

- 外部ベンダーのQAチームを結成し、様々な端末でのバリエーションテストやリグレッションテストを十分に行い、単体テストはカバレッジを一定以上満たすなどの基準を開発に取り入れたことで、初動トラブルも少なくリリースできました。
- テックリードとして問題になりそうなコードやセキュリティ実装を入念にチェックし、方針を都度振り返りの場で決めることで、堅牢なシステムを構築。
- 開発後のオーナーアンケートでは、開発力・コミュニケーション力ともにほぼ満点の評価。
- 上記を踏まえ、社内の優秀案件アワードを受賞（半期に一部署2～3案件のみ選出）。
- 次期開発フェーズでは連携先システムが増えたものの規模は大きくなかったため、オーナーや連携先システムの開発ベンダーとの要件調整から実装、ドキュメント更新、テスト、リリースまですべて一人で担当（リリース後の致命的なトラブル0件）。

#### 修理工場マッチングサービスの開発（PoC → 全国展開フェーズ）
- **期間**：2024年04月～2024年09月
- **担当フェーズ**：要件定義、設計、実装、テスト、リリース
- **環境**：JavaScript / TypeScript / HTML / CSS / Vue.js / Nuxt.js / Node.js（Lambda）/ PostgreSQL / AWS
- **規模**：システム単体 全10名程度、連携システム全体 全30名程度
- **役割**：プロジェクトマネージャー・アーキテクト・開発者

**業務内容**

- アーキテクチャ設計
  - AWS Fargate + Aurora Serverless構成、フロントはNuxt.js
  - 社内システム2つとの連携の仕様調整
  - グループのセキュリティ基準（金融系）に沿った実装方針の見直し
- プロジェクト全体の進捗管理、オーナーやステークホルダーとの要件調整、交渉、工数コストの見直し
- アジャイル開発に伴う問題や改善点を洗い出し、スクラムマスターやメンバーへ提言して改善を実施
- 案件自体の工数予算が不足していたため、開発マスト分のはみ出た部分は開発者として参画して実装
- 次期開発のための要件検討、スコープ策定、工数コスト見積、連携先システムの開発ベンダーとの仕様調整

**実績・取り組み**

- PoCから全国展開に伴う本格実装のためのアーキテクチャ設計を担当。連携システムが多く、保険ならではの基幹システムも含まれ連携パラメータが多岐に渡ったため、開発フェーズに入ってもパラメータ調整を余儀なくされましたが、次期開発部分との開発ラインを明確にすることで過不足なくパラメータ仕様を取り決めることができました。
- 各修理工場に修理予約管理のプラットフォームを提供するシステムであったため、社内セキュリティ基準を満たすための調整に非常に時間がかかり開発終盤でのFIXとなりましたが、工数不足を自ら開発者として参画することで解決しました。
- 問題になりそうなコードやセキュリティ実装についてリファクタリング箇所を挙げ、品質向上に努めました。
  - リリースに伴う外部ベンダーによるシステム脆弱性診断での検知を限りなく少なく抑えることができました。

- **期間**：2022年04月～2024年09月
- **担当フェーズ**：（改修案件がある場合）要件定義、設計、実装、テスト、リリース
- **環境**：JavaScript / TypeScript / HTML / CSS / Vue.js / Nuxt.js / Node.js（Lambda）/ PostgreSQL / AWS

- 脆弱性のあるライブラリのアップデートやブラウザ仕様変更のための改修
- アラート検知に伴う原因調査、オーナーへの報告、必要に応じて改修
