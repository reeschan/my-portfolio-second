# 0026. 表示言語は Cookie で持ち、文言は自前の辞書で持つ

- 状態: 提案中
- 日付: 2026-10-12
- 関連: [PBI-0014](../pbi/0014-locale-switch/PBI.md)、[ADR 0005](0005-component-architecture.md)

## 背景

右上のスイッチで日本語と英語を切り替えられるようにする。言語の持ち方 (URL か Cookie か) と、文言の持ち方 (ライブラリか自前か) を決める必要がある。
対象は 2 言語・7 ページで、文言の量は多くない。

## 決定

- **言語は Cookie (`locale`) で持つ**。URL は言語で分けない
  - ルートのレイアウトが `cookies()` で読み、`<html lang>` に出し、Client Component には `LocaleProvider` (`lib/i18n/locale-context.tsx`) で配る
  - Server Component は `getLocale()` / `getMessages()` (`lib/i18n/server.ts`) で読む
  - スイッチは Server Function `setLocale` (`lib/i18n/actions.ts`) で Cookie を書く。書くと Next.js が今のページを新しい言語で描き直す
  - Cookie がない・知らない値のときは日本語 (これまでの表示を変えない)
- **文言は自前の辞書で持つ**。ライブラリは入れない
  - 画面の固定の文言は `data/messages/ja.ts` が正本で、`en.ts` は同じ型 (`Messages`) を満たす。キーの書き忘れは型チェックで落ちる
  - 表示データの英語版は `data/en/*.ts`。日本語版と組にする入口は `data/localized.ts`

## 検討した選択肢

| 選択肢 | 良い点 | 悪い点 |
| --- | --- | --- |
| Cookie で持つ (採用) | URL もページの置き場所も変わらず、差分が小さい。既存の E2E とリンクがそのまま使える | 全ページがリクエストごとの描画になる。英語版が検索エンジンに別ページとして載らない |
| URL で分ける (`app/[lang]/...`) | 英語版が検索に載り、リンクで言語を指定できる | 全ページの移動と、リンク・ナビゲーション・E2E の書き換えが要り、差分が大きい |
| next-intl などのライブラリ | 複数形・日付・メッセージの書式が揃う | 2 言語・文言が少ない今は機能が余る。依存とその更新が増える |
| 自前の辞書 (採用) | 依存なし。型で漏れを検出できる。文言が data/ に置かれ、決まり (ADR 0005) に沿う | 複数形などの書式は自分で書く |

## 結果

- ルートのレイアウトで `cookies()` を読むので、全ページが静的な事前描画からリクエストごとの描画に変わる。ページは軽く、Vercel の関数で描くので許容する
- 英語版を検索に載せたくなったら、URL で分ける方式に置き換える (新しい ADR を書く)
- 文言を足すときは `data/messages/ja.ts` と `en.ts` の両方に足す。データを足すときは `data/en/` にも足す (作品は英語が欠けていると日本語のまま出る)
- E2E は既定の日本語で回り、英語は `e2e/i18n.spec.ts` が Cookie を入れて確かめる

## 追記 (2026-10-23)

- 描き方は [ADR 0035](0035-cache-components-and-prefetch.md) に移った。言語を Cookie で持つことと辞書の持ち方はこの ADR のまま
- ルートのレイアウトは Cookie を読まなくなった。`<html lang>` は `<head>` のスクリプトが Cookie で書き換え、言語の中身はページの `<Suspense>` の中で Cookie を読んで描く。上の「全ページがリクエストごとの描画に変わる」は、0035 で殻を作り置きする形に改めた
