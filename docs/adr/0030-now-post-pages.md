# 0030. /now の記事に 1 件ずつのページ (/now/[id]) を持たせ、一覧のダイアログをやめる

- 状態: 提案中
- 日付: 2026-10-16
- 関連: [PBI-0023](../pbi/0023-now-post-pages/PBI.md)、[ADR 0015](0015-now-posts-storage-and-markdown.md)、[ADR 0029](0029-site-url-and-seo-metadata.md)

## 背景

- /now の記事は一覧のカードを押すとダイアログで全文を出す作りで、記事ごとの URL がない。RSS のリンクは `/now?post=<id>` で、canonical は `/now` になる
- ダイアログはサーバーでは描かれないので、HTML には一覧の抜粋 (3 行) しか入らない。検索エンジンは記事の本文を読めず、記事ごとの題名・説明・公開日も渡せない
- sitemap は `lib/navigation.ts` のページだけを載せ、記事を載せていない

## 決定

- 記事ごとのページを `/now/<id>` に作る (`app/now/[id]/page.tsx`)。id は保存先の id (`crypto.randomUUID()`) をそのまま使い、URL には `encodeURIComponent` をかける。URL は `lib/now/feed.ts` の `nowPostPath()` だけから作る
- ページはリクエストごとに保存先から読み (`connection()`)、本文の Markdown をサーバーで描く。Mermaid の図はいまどおりブラウザで描く (コードの文字は HTML に入る)
- 知らない id は 404。保存先が設定されていない本番も 404。保存先が落ちたときは例外にして 5xx を返す (空のページを 200 で返して検索エンジンに覚えさせない)
- metadata は ADR 0029 の `pageMetadata()` で作る。題名は記事の題、説明は本文の抜粋、canonical は `/now/<id>`。OGP は `type: article` と公開日・更新日を付ける。画像はサイト共通のまま
- 構造化データとして schema.org の `BlogPosting` を JSON-LD で埋める。`<` は `<` にして script の中で閉じられないようにする
- sitemap に記事を足し、`lastModified` に更新日 (なければ公開日) を入れる。保存先が読めないときは記事を載せずに固定のページだけを返す
- RSS の item のリンクを `/now/<id>` にする。guid は id のまま (`isPermaLink="false"`) にし、リーダーに既読の記事を新着と見なさせない
- 一覧のカードは記事のページへのリンクにし、ダイアログをやめる。`/now?post=<id>` (これまでの RSS のリンク) は `/now/<id>` に恒久的にリダイレクトする
- タブは `/now/<id>` でも「Now」を選んだ状態にする

## 検討した選択肢

| 一覧から記事への開き方 | 良い点 | 悪い点 |
| --- | --- | --- |
| **リンクで記事のページに移る (採用)** | 1 つの描き方で済み、URL をそのまま共有できる。戻るボタンで一覧に戻れる | 一覧の上に重ねて読む今の体験はなくなる |
| intercepting routes でダイアログに出し、URL だけ変える | 今の見た目を残せる | 一覧の中と単独のページで描き方が 2 つになる。表示言語の Cookie と並行ルートの組み合わせを確かめる手間が大きい |
| ダイアログを残し、記事のページを別に足す | 変更が小さい | 同じ記事に 2 つの入口があり、どちらを共有すればよいかが分かりにくい |

| URL の形 | 良い点 | 悪い点 |
| --- | --- | --- |
| **保存先の id (`/now/<uuid>`) (採用)** | 題名を変えても URL が変わらない。保存の形を変えずに済む | URL から中身が分からない |
| 題名から作る slug | URL が読める | 日本語の題の扱い・重複・改題のときのリダイレクトの管理が要る |

## 結果

- 検索エンジンが記事の本文・題名・公開日を読めるようになり、記事ごとに検索結果に出られる
- 記事を足すと sitemap と RSS に自動で載る。デプロイは要らない
- ダイアログの部品 (`now-post-dialog.tsx`) は消える。`/works` の詳細ダイアログはそのまま
- 記事のページは `@smoke` (必須) の対象になる。E2E は `routes("/now/[id]")` で数える
