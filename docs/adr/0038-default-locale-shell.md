# 0038. タブ付きのページの本文は、既定の言語で殻に置く

- 状態: 提案中
- 日付: 2026-10-25
- 関連: ADR 0035 (Cookie の `<Suspense>` と殻)、0036 (見出しとパネルを殻に置く)、0026 (言語は Cookie)、PBI-0036

## 背景

ADR 0035 は、表示言語を Cookie で読む部分を `<Suspense>` に閉じ込め、ページの中身をその中で描いた。殻に残るのは fallback (空の帯と読み込み中の枠) だけで、本文はリクエストのあと `<div hidden id="S:">` に流れる。JS がその穴を差し替える。`htmlLimitedBots` に入っている相手は描き終わるまで待つが、一部の AI クローラーやリンクのプレビューは待たず、隠れた穴も読まない。

本番の HTML (2026-10-25) では、`/works`・`/now`・`/skills` を含むタブ付きのページの本文が、どれもこの穴の中だけにあった。ADR 0036 のパネル内の `<Suspense>` は、`/works` と `/now` では本文をさらにもう一段の穴にしていた。

`use cache` の中身は、Cookie などのリクエストデータより前に描けば殻に入る。リクエストデータを読んでから描くと、殻に入るのは fallback だけになる。

## 決定

- `SiteFrame` の Cookie の `<Suspense>` は、タブバー・アドレスバー・`<html lang>` の合わせ直しだけを包む。本文の入れ物 (`children`) はその外に置く
- タブ付きの各ページは `Localized` (`components/layout/localized.tsx`) で包む。fallback は既定の言語 (日本語) で描いた見出しと本文、中では Cookie の言語で同じ木を描き直す。fallback が殻にそのまま入るので、JS を動かさない相手は日本語の本文を読める。言語の切り替えは、中の木が届いたときの差し替えで残す
- 同じ RSC のスロットを fallback と中の両方に置くと片方にしか出ないので、描く木は関数で都度作る
- `TabPageTemplate` のパネル内の `<Suspense>` は外す。本文をそこで待つと、殻に置く既定言語の本文まで後から差し込む穴になる。読み込み中の線 (`PanelBodyFallback`) は、本文が殻に無い 404 の枠 (`PanelFrameFallback`) だけが使う
- `/now` の記事一覧は、Cookie を読む前に `"use cache"` で読む。失敗したかどうかだけを渡し、文言は描く言語の辞書から取る (日本語の失敗文言を作り置きの鍵にしない)
- 記事のページ (`app/now/[id]`) は、これまで `SiteFrame` の `LocaleProvider` が配っていた言語を、ページ自身が配る。ページはもともと Cookie を `<Suspense>` の外で読んでいる (`instant = false`)

## 検討した選択肢

| 選択肢                                                                       | 良い点                                                                                               | 悪い点                                                                                          |
| ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 既定言語の本文をページの fallback にし、Cookie の言語は中で差し替える (採用) | URL も先読みも言語の切り替えも残る。クローラーは Cookie を送らないので、殻の日本語が検索の中身になる | 英語の閲覧者は、差し替えが届くまで日本語の本文が一瞬出ることがある                              |
| 本文を `<Suspense>` の外に置き、言語はクライアントだけで切り替える           | 殻が単純                                                                                             | ハイドレーションの前に言語を合わせるには描画後の state 更新が要る。このリポジトリはそれをしない |
| `htmlLimitedBots` にクローラーを足す                                         | ページの形を変えない                                                                                 | 一覧に無い相手は今のまま読めない。一覧の保守が要る                                              |
| URL を言語で分ける                                                           | 英語も静的な HTML になる                                                                             | ADR 0026 で見送った差分がそのまま残る                                                           |

## 結果

- JS を動かさない相手にも、タブ付きのページの日本語の本文が最初の HTML で読める。ADR 0035 の「JS を切ると本文が出ない」は、この決定で置き換える
- 英語は今までどおり Cookie で出し分ける。先読みは、中の `"use cache"` (`stale` が 5 分以上) が App Shell に入る条件を変えていない
- 直接開いたときの殻は、空の帯ではなく既定言語の本文になる。タブバーは言語が届くまで空の帯のまま
- パネル内の読み込み中の線は、タブ付きのページの移動では出さない。先読みが無いときも、殻の本文 (見出しとパネル) が見えたまま替わる
