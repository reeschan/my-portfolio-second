# PBI-0014 「準備中」のお知らせを消し、右上で日本語と英語を切り替えられるようにする

- 状態: 進行中
- 起票日: 2026-10-12
- 依頼者: リポジトリの持ち主
- 作業記録: [WORK.md](WORK.md)
- 関連 ADR: [0026](../../adr/0026-locale-cookie-and-dictionaries.md)

## 背景・目的

サイトは公開して中身もそろったが、全ページの上部に「🚧 サイトは現在準備中です。5月に完成予定です」のお知らせが残っていた。RSS にも同じ「準備中」の記事が 1 件だけ載っていた。
また、日本語しか読めず、海外の閲覧者や英語で読みたい採用担当に経歴・スキル・作品が伝わらない。

## やること

- 上部の「準備中」のお知らせ (`AnnouncementBanner`) と、RSS の「準備中」の記事を消す
- 画面の右上 (アドレスバーの右端、RSS ボタンの隣) に EN / JP のスイッチを置き、全ページを英語と日本語で切り替えられるようにする
- 選んだ言語は Cookie に残し、他のページに移っても、再読み込みしても、次に開いても同じ言語で出す
- 英語にするもの: タブ・見出し・ボタンなど画面の固定の文言、概要・経歴・スキル・ワークのデータ、背景テーマの名前、チャットの挨拶と質問の候補、`<html lang>`、ページの title と description

## やらないこと

- URL を言語ごとに分けること (`/en/...`)。検索エンジン向けの英語版は今回は狙わない (ADR 0026)
- /now の記事の翻訳 (記事は日本語だけで書く。英語のときは「日本語で書いている」と断り書きを出す)
- チャットのシステムプロンプトと回答の言語の変更 (変えると privacy eval のやり直しが要る)
- API が返すエラーの文言の英語化
- 3D 背景のシーンそのもの
