# PBI-0016 概要のプロフィールにメインのアイコンを丸く載せる

- 状態: 進行中
- 起票日: 2026-10-13
- 依頼者: リポジトリの持ち主
- 作業記録: [WORK.md](WORK.md)
- 関連 ADR: なし

## 背景・目的

概要のプロフィールは名前と文章だけで、誰のページかが一目で分かりにくい。持ち主が用意したメインのアイコンを、丸く切り抜いて名前の横に出したい。

## やること

- 持ち主から受け取ったイラストを正方形に切り抜き、`public/profile/avatar.webp` に置く
- プロフィールのデータ (日本語・英語) にアイコンのパスと代替テキストを持たせ、/overview で丸く出す

## やらないこと

- ほかのページ (チャット・OGP 画像など) でのアイコンの利用

## 受け入れ条件

| # | 条件 | 確かめ方 |
| --- | --- | --- |
| 1 | /overview にアイコンが代替テキスト付きで出て、画像が読み込めている | e2e/content.spec.ts (/overview @content) |
| 2 | アイコンのファイルが public/ にあり、日英で同じ画像を使い、代替テキストが空でない | test/data/overview.test.ts |
| 3 | /overview に重大なアクセシビリティ違反がない | e2e/a11y.spec.ts |
| 4 | lint・型・ユニット・書式・ビルドと必須観点の穴の検査が通る | `pnpm commit-gate` |
