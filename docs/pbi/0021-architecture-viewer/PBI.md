# PBI-0021 ワークのアーキテクチャ図を拡大して読めるようにする

- 状態: 進行中
- 起票日: 2026-10-13
- 依頼者: リポジトリの持ち主
- 作業記録: [WORK.md](WORK.md)
- 関連 ADR: なし ([0024](../../adr/0024-works-detail-data-and-diagrams.md) の図をそのまま使う)

## 背景・目的

- ワークの詳細ダイアログの図は、幅がデスクトップで約 850px、スマホで約 340px しかない。D2 の図は横 2,000〜2,800px あるので、図の中の文字が読めない
- アーキテクチャ図は作品の設計を伝える中心なので、読める大きさで見せたい

## やること

- 詳細ダイアログの図を押すと、画面いっぱいの拡大表示を開く
- 拡大表示では倍率を 100% (画面の幅に収める) から 400% まで切り替え、枠の中を縦横にスクロールして見回せる
- 元の SVG を新しいタブで開くリンクを置く (ブラウザの拡大や保存を使えるように)
- 拡大表示を閉じると作品の詳細に戻る

## やらないこと

- カードのサムネイルを画面のスクリーンショットに替えること (画像の用意が要るので別の PBI)
- ピンチやホイールでの連続的な拡大 (ブラウザの機能と元の SVG のリンクで足りる)

## 受け入れ条件

| # | 条件 | 確かめ方 |
