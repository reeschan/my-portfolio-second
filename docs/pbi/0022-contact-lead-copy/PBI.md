# PBI-0022 お問い合わせの冒頭の一言で、仕事を募っていることを伝える

- 状態: 進行中
- 起票日: 2026-10-16
- 依頼者: リポジトリの持ち主
- 作業記録: [WORK.md](WORK.md)
- 関連 ADR: なし

## 背景・目的

お問い合わせのフォームの冒頭は「お仕事のご依頼やご質問は、こちらからお送りください。」だけで、仕事を探していることが伝わらない。
持ち主の言葉で「AI を使いすぎてずっと金欠なので、なんでもやるので仕事をください」と、くだけた一言で募りたい。

## やること

- `/contact` のフォームの上の文 (`contact.lead`) を、仕事を募る一言に変える。日本語 (`data/messages/ja.ts`) と英語 (`data/messages/en.ts`) の両方

## やらないこと

- フォームの項目・送り先・ページの metadata (`contact.description`) は変えない

## 受け入れ条件

| # | 条件 | 確かめ方 |
| --- | --- | --- |
| 1 | `/contact` を開くと、フォームの上に仕事を募る一言が出る | e2e/contact.spec.ts (@interaction) |
| 2 | 英語に切り替えると、同じ内容の英語の一言が出る | `en.ts` が `ja.ts` と同じ型なので `pnpm typecheck` で漏れを検出。画面は目で確かめる |
