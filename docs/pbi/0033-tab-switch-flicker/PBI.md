# PBI-0033 タブを切り替えたときのちらつきをなくす

- 状態: 進行中
- 起票日: 2026-10-24
- 依頼者: リポジトリの持ち主
- 作業記録: [WORK.md](WORK.md)
- 関連 ADR: [0036](../../adr/0036-tab-page-heading-in-shell.md)、[0035](../../adr/0035-cache-components-and-prefetch.md)

## 背景・目的

PBI-0031 でタブを押してから中身が替わるまでを縮めたあと、タブ付きのページどうし (/overview → /career など) を切り替えたときに画面がちらつくようになった。先読みが済む前に押すと (本番では読み込み直後の 1 回目、開発サーバーではほぼ毎回)、`app/(tabs)/loading.tsx` の読み込み中の枠が出て、見出しが消え、本文のパネルが灰色の線だけになってから新しいページに替わる。替わるのが 2 回になるので、ちらついて見える。先読み済みのときの速さ (約 19ms) は保ったまま、このちらつきをなくす。

## やること

- `app/(tabs)/loading.tsx` を外す
- タブ付きのページの見出し (h1) と本文のパネルの外枠を、Cookie に依らない殻に置く。読み込み中の線は、Cookie に依る本文 (`"use cache"` の部品) のところにだけ出す
- 変える前と後で、切り替えの途中に見出しが消えるか・読み込み中の枠が出るかを、同じ手順で比べる

## やらないこと

- 押したタブに「読み込み中」の印を付けること
- /works の画像が初めて開いたときに後から出ること (画像の読み込みで、ちらつきとは別)
- /now の記事のページ (`/now/<id>`) と 404 のページの形を変えること (見出しがタブ名ではないため。今も `<Suspense>` で包んでいる)
- 先読みの方式 (Partial Prefetching) の変更

## 受け入れ条件

| # | 条件 | 確かめ方 |
| --- | --- | --- |
| 1 | 先読みが済んでいないタブを押しても、切り替えの途中で見出しと本文のパネルが消えない。読み込み中の線が出るのはパネルの中だけ | e2e/navigation.spec.ts (@navigation) |
| 2 | 先読み済みのタブを押してから見出しが替わるまでの時間が、変える前と同じ程度 (数十 ms) のまま | 手元の本番ビルドで測る (WORK に残す) |
| 3 | 英語に切り替えたあとにタブを押すと、見出しも英語で出る | e2e/i18n.spec.ts (既存) |
| 4 | 各ページの h1 が 1 つで、タブ名と同じ | e2e/seo-pages.spec.ts・e2e/smoke.spec.ts (既存) |
