# PBI-0039 unslop の観点で見た目の AI っぽさを取る

- 状態: 進行中
- 起票日: 2026-11-10
- 依頼者: リポジトリの持ち主
- 作業記録: [WORK.md](WORK.md)
- 関連 ADR: [0004](../../adr/0004-design-theme.md) (追記する)

## 背景・目的

サイトの見た目に、生成 AI が作った画面によくある癖が細部に残っている。ホバーでカードが浮き上がる・画像が拡大する、太すぎる見出し、アクセントの青をあちこちに使う、暗い面に影を付ける、既定の Inter のまま、「！」で始まるあいさつ、などがそれにあたる。閲覧者 (採用担当や発注者) にとって、どこかで見たテンプレートに見える。

[heydamir/unslop](https://github.com/heydamir/unslop) (CC BY 4.0、Damir Sokolovsky) の兆候の一覧と目安の値で画面を点検した。結果は軽い段階 (Light slop) だったので、見つかった点だけを直す。方向性は次のとおり持ち主と合意した。

- 何のサイトか: フリーランスのフルスタック開発者の経歴と作品を、採用担当や発注者に見せる
- 性格: 正確・落ち着いている・少し遊び心がある / 世界: 夜のブラウザと開発ツール
- 見せ場: 3D 背景とワークのアーキテクチャ図 / このサイトだけの印: ブラウザのタブとアドレスバー

## やること

- 押せるカード (作品・/now の記事) とタブのホバーを、色と面の変化だけにする。浮き上がり・拡大・`transition-all` をやめる
- ページの h1 を `font-semibold` にし、40px 未満の見出しから `tracking-tight` を外す
- チャットのあいさつと入力欄の案内 (日英) から「！」「!」と末尾の「...」を取る
- アクセントの青を、意味のある所 (現在のタブ・リンク・継続中・送信) だけにする。経歴のカードの上の太い青線、タイムラインの点の青、アバターの青い縁、資格の囲みの薄い青をやめる
- ダークの面の影 (経歴のカード・アバター) をやめ、面の段差と細い線で奥行きを出す
- バッジを pill から角丸 (`rounded-md`) にする
- 書体を Inter から Geist (本文) と Geist Mono (日付・アドレスバーの URL・技術のタグ) に替える
- `docs/design/theme.md` と ADR 0004 に今回の決まりを書く

## やらないこと

- 既定の 3D 背景「ガラス」(紫の光とスモーク) の変更。unslop では「紫の星雲」にあたるが、持ち主が残すと決めた
- ガラスの面・タブ風の UI・配置・機能の変更 (unslop も「流行を別の流行に置き換えない」とする)
- 読み込み中のスケルトンとチャットの「考え中」の点滅 (実際に処理中を示すので残す)
- アドレスバー・言語の切り替え・RSS のボタンの丸い形 (ブラウザを写した印)
- unslop のスキルをリポジトリに入れること (観点として参照しただけ)
